## 已收到的手机反馈

用户已反馈比赛内风格、心有灵犀、逆足精度与频率、解约正常，本轮保留现有实现。反馈限于已测场景，不能扩展成所有手机、卡片和触发条件均已验证。“心有灵犀比赛可用”与“已确认可供新增训练的技能编号”分开记录，后者仍未确认。

本轮新反馈包括：设置浮窗遮挡入口、公告反复弹出、预置球员未进普通列表、技能重开变少、升级后等级 0/100 与点数 -2、正常完赛显示放弃落败。对应改动如下。球衣反馈尚缺具体球队与主客场表现，保留待复现状态。

## 本地验证与构建核验

本轮完整 Python 回归 **265 项通过，无跳过**；Java 资源与更新频道 **55 组、253 项断言通过**。测试包括旧版负例、技能五槽与删除、迁移保护、升级回复、结算与个人统计、公告、原生菜单补丁及保存恢复。它们不替代 Android 游戏运行与实战验证。

真实 seed 独立副本迁移后共 6351 份实例，6328 份预置赠卡位于普通列表，种子储备数为 0；serial 唯一，已有训练账本和原输入校验保持。真实用户存档中自行储备的其他卡不会因此清空。本地测试只操作临时数据库、协议副本及限定原生函数，不执行手机游戏或抽卡动画。

原始输入使用已发布 1.1.1 APK；test.3 针对 libUE4 的技能候选和帧率菜单应用受检、等长、无重叠范围补丁，原始游戏 DEX 1–6 和其他核心成员独立核验，不能再称“原生库完全未改”。构建报告目标目录为 `release/v1.2.0-test.3/`，包括 `verification.json`、`native-ui-patch.json` 与 `SHA256SUMS`。下载校验以本轮实际发布附件为准，不复制旧轮次哈希或字节数。

## 安装与手机验收

测试包 `com.efootball.revival.test`、名称 `efootxi 测试`、系统分配本地可用端口；正式包 `com.efootball.revival.local` 使用原有目录与 8085 端口。两包并存，正式存档不自动搬迁。设备基线 Android 12/API 31、ARM64；版本名 1.2.0，构建号 1202，标签 `v1.2.0-test.3`。

优先验收顺序：

1. 覆盖安装测试包，两次重启、资源完整后飞行模式进入；不先卸载已有存档。
2. 普通球员列表显示预置卡，已培养、已解约与手动储备状态保留。
3. 原生技能训练五槽、先填后槽、逐槽替换、删除后补位，以及退出重进与半场换人。
4. 升级后立即查看经验和点数、手动分配，无需重启刷新。
5. 三种本地模式正常踢完，核对比分与胜负，赛前/赛后/重启后比较出场、进球、助攻。
6. 原生公告入口、未读红点、重启已读；帧率全部旧档与 120 档保存，实际帧率、耗电及比赛时间流速。
7. 带具体球队的球衣复现、组合包即时刷新、问题设备黑屏和抽卡闪退。
