## 已定位并实施的改动，待手机验收

1. 资源下载频繁停下，要求反复点击重试。已有断点与 ETag 保存，但短暂超时、断流、429/5xx 没有自动重试。本轮在原下载器上实现可暂停的自动续传与退避；预算按连续无进展计数，取得新字节后重置。
2. 我的联赛开赛持续转圈，AI 组别可进入。已补齐赛季专用阵容保存、教练与战术持久化，以及原生 START 发送空名单时读取保存阵容的流程。执行真实 ARM64 序列化确认该请求形态，旧版会明确拒绝。成功租借的卡也是有效拥有实例，沿用原有验证。
3. test.3 中 AI 组别正常踢到终场仍显示放弃落败，个人进球等记录为 0。从实际已发布 APK 提取纯解析器复现：正常结束原因 NOERR、比分 11:0、默认放弃标志 YES，被旧处理改成 0:3 并排除统计。现以明确结束原因为准，保留真正弃赛及异常拒绝；并补原生统计更新列表的即时刷新。已有数据库总数仍为整数，不把它误改成更新通知的数组。详见 [结算调查](test4-settlement-investigation.md)。
4. 更新页来源声明改为：efootxi 第一版基于 73@7othree 版本开发，已获得修改许可。更新页的 7othree 使用粗体；纯文本公告与元信息不显示 Markdown 星号。
5. 原生通知新增「本地测试反馈信息」，只在主动查看时生成最多三场只读摘要，包含结束标志、返回结果及统计保存情况；不展示账号、令牌或球员姓名，不自动发送。已读状态仍保存，生成报告失败不阻断其他公告。
