## 有用的差异与没有沿用的部分

1. 技能训练回执加入登录会话区分，避免重新登录后同一请求编号误命中旧训练。这一思路已结合当前事务与最新技能快照逻辑实现，未直接替换整份文件。
2. 参考包仍不能作为技能槽位合同的正确性依据。当前原生点击、发送和读取三个位置证明 `training_index` 为 0–4；test.2 后端按 1–5 解释，会覆盖前一个技能槽。test.3 按原生编号及空位标记 74 修复，保持五槽位置。
3. 升级后的 `0/100` 不靠拷贝参考代码解决。参考包仍未填入 `CMD_USE_MYCLUB_ITEM` 真正读取的根字段 `experience`。当前原生解码路径 `0x7947980..0x79479b4 → 0x7553b48` 可直接复现缺字段时的默认 0/100；新回复补齐真实等级，训练数学及已存进度不变。
4. 正常结算采用当前游戏原生枚举证据。`NORMAL/NORMAL` 中的异常原因不被识别时会落入 `DISCONN_HB`；test.3 使用 `NORMAL_END/NOERR`，保留真实弃赛，不强制胜利。旧回执仅在请求一致时修显示，不重复计算积分或统计。
5. 参考包的联赛球衣仍可能沿用 Dream Team 已存球衣。当前按联赛所选球队发送球衣，避免该继承路径，因此没有倒退移植参考条件。具体手机球衣反馈尚待明确，不能仅凭接口数据断言所有球衣显示正常。
6. 用户已经确认的比赛风格、心有灵犀、逆足精度与频率、解约逻辑保留。新参考包不是替换这些映射的理由。
